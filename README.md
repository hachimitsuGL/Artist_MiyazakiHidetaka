# 魂の匠 宮崎英高

ゲームクリエイター・宮崎英高の人物像と作品の魅力を紹介するWebサイトです。ダークファンタジーの雰囲気を取り入れ、作品の世界観や芸術性をまとめています。\
GitHub Page：https://hachimitsugl.github.io/Artist_MiyazakiHidetaka/

## 主な内容

- **人物紹介**：経歴やゲーム制作に対する考え方を紹介。
- **作品集**：『Demon's Souls』『Dark Souls』『Bloodborne』『SEKIRO』『ELDEN RING』などの代表作品を掲載。
- **ELDEN RINGの探索**：地図上のマーカーから各地の紹介や美術分析を表示。
- **芸術分析**：建築・人物・道具を通して、作品の美学や物語表現を考察。

## 使用技術

HTML / CSS / JavaScript / Leaflet

## 閲覧方法

`index.html` をブラウザで開いてください。外部ライブラリやWebフォントの読み込みにはインターネット接続が必要です。
